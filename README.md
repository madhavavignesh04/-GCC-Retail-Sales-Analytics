# GCC Retail Sales Analytics Dashboard

## Project Overview
An interactive retail sales analytics project built using Tableau
to analyze sales performance, profitability, and product contribution.

## Key Features
- Total Sales, Total Profit, and Total Orders KPIs
- Monthly Sales Trend Analysis
- Product-wise Sales Performance
- Category-wise Sales Contribution
- Category-wise Profit Analysis
- Interactive Category Filters

## Tools Used
- Tableau Desktop
- Data Visualization
- Retail Sales Analytics

## Business Objectives
- Identify sales trends over time
- Compare product and category performance
- Understand profit contribution
- Support data-driven business decisions

Tableau workbook and project documentation are available
